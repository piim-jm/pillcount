# นับเม็ดยา (PillCount)

เว็บแอปนับเม็ดยาจากกล้องมือถือแบบสด อ่าน QR รหัสยาบนสติกเกอร์ และเก็บประวัติการนับไว้ในเครื่อง

## วางบน GitHub Pages

1. เข้า github.com กด **New repository** ตั้งชื่อ `pillcount` เลือก **Public** แล้วกด **Create repository**
2. กดลิงก์ **uploading an existing file** แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, counter.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, README.md) กด **Commit changes**
3. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch** เลือก `main` และ `/ (root)` แล้วกด **Save**
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/pillcount/`

## เริ่มใช้ครั้งแรก

1. เปิดลิงก์ใน Chrome บนมือถือ แล้วกดอนุญาตกล้อง
2. เมนู ⋮ → **เพิ่มลงในหน้าจอหลัก** จะได้ไอคอนเหมือนแอป
3. แท็บ **ตั้งค่า** → **นำเข้าจากไฟล์ Excel** เลือกไฟล์ Stock Balance เพื่อให้สแกน QR แล้วขึ้นชื่อยา

## ข้อมูลอยู่ที่ไหน

- รายการยา ประวัติ และรูป เก็บใน IndexedDB ของเบราว์เซอร์บนมือถือเครื่องนั้นเท่านั้น ไม่ส่งขึ้นเซิร์ฟเวอร์
- ใน repo ไม่มีข้อมูลโรงพยาบาลหรือผู้ป่วย รายการยานำเข้าจากไฟล์ในเครื่อง
- QR บนสติกเกอร์มีแค่รหัสยา 14 หลัก แอปไม่อ่านชื่อหรือ HN ผู้ป่วย
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย ใช้ **ตั้งค่า → ส่งออกไฟล์สำรอง** เป็นระยะ

## แก้ไขในอนาคต

อัปโหลดไฟล์ใหม่ทับใน repo แล้วเปลี่ยน `CACHE` ใน sw.js (เช่น `pillcount-v2`) เพื่อให้มือถือโหลดเวอร์ชันใหม่

## โมเดล AI (model.onnx)

YOLOv8n เทรนจากชุดข้อมูลเปิด Ultralytics Medical Pills (92 รูป) แล้วเทรนต่อด้วยรูปถุงยาจริงจากห้องยา 41 รูป (รอบ 1, ต.ค. 2569)
ทดสอบกับรูปที่ไม่ได้ใช้เทรน 11 รูป: คลาดเฉลี่ย 1.1 เม็ด (โมเดลก่อนหน้า 7.2 เม็ด)
โมเดลและชุดข้อมูลอยู่ภายใต้สัญญาอนุญาต AGPL-3.0 ของ Ultralytics — repo นี้เปิดซอร์สสาธารณะตามเงื่อนไขนั้น
แอปใช้ AI เป็นการนับซ้ำตอนหยุดภาพ เทียบกับวิธีแยกสี ถ้าสองวิธีไม่ตรงกันจะเตือนให้ตรวจ
